# Spindle / Laser Toggle Plugin v5

Плагин Candle для переключения инструментов ШПИНДЕЛЬ ($32=0) / ЛАЗЕР ($32=1).

## Смена скоростей при смене инструмента (v5)

**Переключение инструмента переключает и скорости на станке.**
Значения берутся из вкладки Candle **«Информация о станке»** (та самая
настройка со скриншота: скорость шпинделя мин/макс, мощность лазера мин/макс)
и подставляются при каждом переключении:

- режим ШПИНДЕЛЬ → `$30` = макс. скорость шпинделя, `$31` = мин.;
- режим ЛАЗЕР → `$30` = макс. мощность лазера, `$31` = мин.

**Запись — сразу, без предварительного чтения и сравнения.** При переключении
уходит ОДНА посылка из четырёх команд:

```
M5          <- остановка инструмента перед сменой режима
$32=1       <- режим лазера
$30=1000    <- макс. мощность лазера из «Информации о станке»
$31=0       <- мин. мощность лазера из «Информации о станке»
```

Цикл «считать → сравнить → записать только отличающееся» не нужен: grbl сам
применяет `$`-команды (одинаковые с текущими значения просто остаются на
месте), а смена инструмента — редкое ручное действие, а не поток команд.
Поэтому переключение мгновенное: один клик — одна посылка, без лишнего
обмена `$$` туда-обратно.

Дополнительно:

- правка «Информации о станке» действует со следующего переключения —
  значения читаются из `app.settings` в момент клика, а не копируются в
  настройки плагина;
- если какого-то значения в «Информации о станке» вдруг нет — пишется только
  `M5`+`$32`: плагин никогда не выдумывает лимиты для станка;
- слайдер «Speed» в главном окне Candle переключается на лимиты активного
  инструмента (значение пересчитывается пропорционально, 50% → 50%; UI-side,
  на станок ничего лишнего не отправляется);
- реальный `$30` контроллера показывается в подсказке кнопки режима;
- `$$`, который Candle сам отправляет после подключения/сброса/хоуминга,
  по-прежнему распознаётся: режим и `$30`/`$31` в подсказке синхронизируются
  с реальным состоянием станка;
- при дисконнекте состояние сбрасывается — на следующем подключении всё
  заново считывается из ответа контроллера.

## Что на странице настроек плагина

- Мощность фокусировки (S) — для кнопки «Фокус»;
- Импульс S / время (мс) — для кнопки «Тестовый импульс»;
- Пояснение про смену инструмента.

## История исправлений

- **v1 (баг):** при каждом переключении плагин записывал в EEPROM фиксированные
  `$30`/`$31` (10000/0 и 1000/0), портя реальные лимиты станка.
- **v2:** запись `$30`/`$31` сделана опциональной (по умолчанию выключена),
  значения по умолчанию — из «Информации о станке».
- **v3:** интерфейсная смена скоростей (слайдер Candle), записи `$30`/`$31`
  не было совсем.
- **v4:** смена скоростей через «считать → сравнить → записать отличающееся».
- **v5 (текущая):** как требуется: при переключении значения `$30`/`$31`
  подставляются из «Информации о станке» и пишутся сразу — одной посылкой
  `M5 + $32 + $30 + $31`, без цикла чтения/сравнения.

## Files

- `script.js` — логика плагина
- `widget.ui` — панель (4 кнопки: Mode, Focus, Pulse, Laser OFF)
- `settings.ui` — страница настроек (фокус, импульс, пояснение)
- `translation_ru.*` — русская локализация
- `config.ini` — манифест плагина
