# Spindle / Laser — переключатель инструментов для Candle

Плагин для Candle добавляет компактную иконочную панель для смены инструмента
**ШПИНДЕЛЬ ($32=0) ↔ ЛАЗЕР ($32=1)** — вместе со сменой скоростей
(диапазона S-параметра `$30`/`$31`).

**Одно нажатие = запрос на смену инструмента.** Плагин читает реальные
значения `$30`/`$31`/`$32` контроллера, отправляет `M5`, `S0`, `G0` и `$32=x`,
после чего ждёт ответ GRBL. Оба лимита `$30` и `$31` из вкладки Candle **«Информация о станке»**
записываются после успешного ответа на `$32`, если соответствующие значения
настроены. Команда `$31` отправляется даже тогда, когда целевой минимум уже
совпадает с текущим значением контроллера. Применение выполняется автоматически,
без модального окна, которое может блокировать переключение в некоторых сборках Candle.
Если настройки ещё не считаны после сброса/подключения, плагин запрашивает `$$`
и автоматически повторяет переключение, определяя исходный режим по ответу GRBL.
При ошибке плагин повторно считывает реальные настройки контроллера.

## Возможности

- **Подтверждение режима самим GRBL.** Интерфейс меняется только после
  ответа `ok` на `$32`. После этого автоматически применяются целевые
  `$30`/`$31` из Machine info; при ошибке плагин повторно запрашивает `$$`.
- **Полный диапазон при каждом переключении.** После подтверждения `$32` плагин
  явно отправляет обе команды `$30` и `$31`, если значения доступны в Machine info.
  Поэтому `$31` не пропускается в журнале даже тогда, когда его значение не меняется.
- **Значения всегда свежие.** Лимиты читаются из настроек Candle в момент
  клика, а не копируются в настройки плагина: правка «Информации о станке»
  действует со следующего переключения.
- **Слайдер «Speed» следует за инструментом.** Диапазон слайдера скоростей в
  главном окне Candle переключается на лимиты активного инструмента, текущая
  позиция пересчитывается пропорционально (50% → 50%). Это только интерфейс —
  на станок ничего лишнего не отправляется.
- **Никаких выдуманных лимитов.** Если какого-то значения в «Информации о
  станке» нет, соответствующий текущий лимит контроллера не меняется;
  отправляются `M5`, `S0` и `$32`.
- **Синхронизация с реальным состоянием станка.** `$$`, который Candle сам
  отправляет после подключения/сброса/хоуминга, распознаётся: режим и
  реальный `$30` контроллера (в подсказке кнопки) подтягиваются из ответа.
  Последний режим запоминается и восстанавливается при запуске. При
  отключении состояние сбрасывается — на следующем подключении всё
  считывается заново.
- **Единообразная локализация.** Один файл перевода (`translation_ru.qm`)
  покрывает всё — кнопки панели, подсказки, страницу настроек и все
  динамические сообщения — штатным механизмом Candle (см. ниже).

## Кнопки панели

| Кнопка | Что делает | Команды на станок |
|--------|------------|-------------------|
| **Режим** (иконка шпинделя/лазера) | смена инструмента | `M5`, `S0`, `$32=x`; затем `$30=…` и `$31=…` после `ok` |
| **Фокус** | луч фокусировки ВКЛ/ВЫКЛ — только в лазерном режиме | `M3 S…` + `G1` (без движения осей) / `M5` + `S0` + `G0` |
| **Импульс** | тестовый импульс лазера — только в лазерном режиме | `M3 S…` + `G1` + `G4 P…` + `M5` + `S0` + `G0` |
| **Выкл** | выключить лазер | `M5` + `S0` + `G0` |

Кнопки «Фокус», «Импульс» и «Выкл» автоматически скрываются в режиме
шпинделя. Подсказка кнопки режима показывает реальный `$30` контроллера и
диапазон скоростей активного инструмента.

## Настройки плагина

- **Мощность фокусировки (S)** — мощность луча для кнопки «Фокус»;
- **Импульс S / время (мс)** — параметры тестового импульса;
- пояснение, как работает смена инструмента.

Скорости в настройках плагина не дублируются — они всегда берутся из
«Информации о станке».

## Локализация

Плагин использует **штатный механизм локализации Candle** — точно так же,
как официальный плагин usercommands. Один файл `translation_ru.qm` покрывает
все видимые строки:

- статические строки панели и настроек (подписи, подсказки, заполнители)
  переводит сам QUiLoader (контекст = `<class>` файла `.ui`);
- динамические сообщения используют `qsTr()` из скриптового движка
  (пустой контекст) — как в официальном плагине;
- заголовок панели «Шпиндель / Лазер» переводит сам Candle (контекст frmMain).

Плагин не определяет язык сам: Candle устанавливает подходящий
`translation_<язык>.qm` до загрузки скрипта, а при его отсутствии интерфейс
просто полностью английский — то есть он либо полностью английский, либо
полностью русский, без смеси. Чтобы добавить другой язык: скопируйте
`translation_ru.ts`, переведите строки и скомпилируйте командой
`lrelease translation_xx.ts`, полученный `.qm` положите рядом с файлами
плагина.

## Установка

1. Найдите папку с программой Candle (рядом с `candle.exe` / `candle`).
2. Скопируйте папку `spindle_laser` целиком в `candleplugins`
   (создайте её при необходимости):

```
Candle/
├── candle(.exe)
└── candleplugins/
    └── spindle_laser/
        ├── config.ini
        ├── script.js
        ├── widget.ui
        ├── settings.ui
        ├── translation_ru.ts
        ├── translation_ru.qm
        └── images/            иконки кнопок
```

3. Перезапустите Candle — в правой панельной области появится строка
   «Spindle / Laser».

## Требования

- Candle с поддержкой JS-плагинов (папка `candleplugins`);
- **grbl v1.1+** — параметр `$32` «laser mode» появился только в v1.1;
- заполненная вкладка «Информация о станке»: скорость шпинделя мин/макс и
  мощность лазера мин/макс — именно из неё плагин берёт `$30`/`$31`.

## История версий

- **v8 (текущая)** — при успешном переключении явно отправляются обе команды
  `$30` и `$31`, если значения доступны в Machine info, даже если одна настройка
  уже совпадает с текущей. Благодаря этому `$31` не пропускается в журнале.
- **v7** — исправлены Focus/Pulse после сброса GRBL и ограничение тестовой
  мощности диапазоном `$31`–`$30`.
- **v6** — единая локализация штатным механизмом Candle: один
  `translation_ru.qm` покрывает панель, подсказки, настройки и динамические
  сообщения (строки `.ui` переводит QUiLoader, динамические — через
  `qsTr()`); собственного определения языка больше нет — интерфейс либо
  полностью английский, либо полностью русский.
- **v5** — смена скоростей при смене инструмента: при каждом переключении
  `$30`/`$31` подставляются из «Информации о станке» и пишутся сразу — одной
  посылкой `M5 + $32 + $30 + $31`, без цикла чтения/сравнения (grbl v1.1
  не пишет в EEPROM одинаковые значения).
- **v4** — смена скоростей через «считать → сравнить → записать отличающееся».
- **v3** — только интерфейсная смена скоростей (слайдер Candle), записей
  `$30`/`$31` не было совсем; блок лимитов убран со страницы настроек.
- **v2** — запись `$30`/`$31` сделана опциональной (по умолчанию выключена),
  значения по умолчанию — из «Информации о станке».
- **v1 (баг)** — при каждом переключении плагин записывал в EEPROM
  фиксированные `$30`/`$31` (10000/0 и 1000/0), портя реальные лимиты станка.
  Если grbl уже «испорчен» прошлой версией — восстановите `$30`/`$31`
  вручную из консоли Candle.



### Фокусировка и импульс в лазерном режиме GRBL

Команды Focus и Pulse сначала запрашивают `$G`, чтобы узнать текущую подачу
`F`, затем отправляют `G1 F...` без координат осей и `M3 S...`. В GRBL 1.1
подача `F` обязательна для `G1`, даже когда оси не перемещаются; это меняет
модальный режим для фокусировки без фактического движения. После теста плагин
отправляет `M5`, `S0`, возвращает `G0` и восстанавливает прежний `F`. Кнопки Focus/Pulse
недоступны, пока плагин не прочитает реальный максимум `$30`; мощность
ограничивается диапазоном `$31`/`$30`. Используйте минимальную практическую
мощность и соответствующую защиту глаз.

Переключение инструмента ждёт `ok` на `$32`, и только затем записывает
диапазон `$30`/`$31` из Machine info Candle. Модальное окно подтверждения не
используется: в некоторых окружениях QtScript класс `QMessageBox` недоступен,
что может привести к тихому отказу от переключения. При отклонении `$32`
плагин перечитывает настройки, а не оставляет интерфейс в неподтверждённом
режиме. При переключении `$30`/`$31` намеренно могут изменяться под новый диапазон.

## Файлы

- `script.js` — логика плагина;
- `widget.ui` — панель (4 кнопки: Режим, Фокус, Импульс, Выкл);
- `settings.ui` — страница настроек (фокус, импульс, пояснение);
- `translation_ru.ts` / `translation_ru.qm` — русская локализация (все
  строки);
- `config.ini` — манифест плагина.
