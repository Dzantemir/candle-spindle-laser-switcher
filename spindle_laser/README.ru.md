# Spindle / Laser — переключатель инструментов для Candle

Плагин для Candle добавляет компактную иконочную панель для смены инструмента
**ШПИНДЕЛЬ ($32=0) ↔ ЛАЗЕР ($32=1)** — вместе со сменой скоростей
(диапазона S-параметра `$30`/`$31`).

**Одно нажатие = запрос на смену инструмента.** Плагин читает реальные
значения `$30`/`$31`/`$32` контроллера, отправляет `M5`, `S0`, `G0` и `$32=x`,
после чего ждёт ответ GRBL. Оба лимита `$30` и `$31` из вкладки Candle **«Информация о станке»**
записываются после успешного ответа на `$32` по одному (каждый — с
подтверждением GRBL и в порядке, при котором промежуточный диапазон в
EEPROM всегда остаётся допустимым), если соответствующие значения настроены.
Команда `$31` отправляется даже тогда, когда целевой минимум уже
совпадает с текущим значением контроллера. Если переключение
перезаписывает **другие** значения контроллера, оно сначала
показывает в подсказке кнопки «старое → новое» и требует повторного
нажатия в течение 15 секунд (подтверждается именно этот переход — текущий
диапазон → целевой, — и запоминается: повтор того же перехода снова в один
клик, а вручную изменённые `$30`/`$31` спросят подтверждение ещё раз) —
заводские значения Candle по умолчанию (шпиндель 0/10000, лазер 0/100) не
могут молча заменить реальные лимиты станка.
Если настройки ещё не считаны после сброса/подключения, плагин запрашивает `$$`
и автоматически повторяет переключение, определяя исходный режим по ответу GRBL.
При ошибке плагин повторно считывает реальные настройки контроллера.

## Возможности

- **Подтверждение режима самим GRBL.** Интерфейс меняется только после
  ответа `ok` на `$32`. После этого автоматически применяются целевые
  `$30`/`$31` из Machine info; при ошибке плагин повторно запрашивает `$$`.
- **Полный диапазон при каждом переключении.** После подтверждения `$32` плагин
  явно записывает обе команды `$30` и `$31` по одной (с ожиданием `ok`) и в
  порядке, при котором промежуточный диапазон в EEPROM всегда допустим
  (`$31` первым, если текущий минимум не ниже нового максимума). Поэтому `$31`
  не пропускается в журнале даже тогда, когда его значение не меняется, а
  ошибка записи прерывает пару с предупреждением, а не оставляет смешанный диапазон.
- **Значения всегда свежие.** Лимиты читаются из настроек Candle в момент
  клика, а не копируются в настройки плагина: правка «Информации о станке»
  действует со следующего переключения.
- **Слайдер «Speed» следует за инструментом.** Диапазон слайдера скоростей в
  главном окне Candle переключается на лимиты активного инструмента, текущая
  позиция пересчитывается пропорционально (50% → 50%). Это только интерфейс —
  на станок ничего лишнего не отправляется.
- **Никаких выдуманных лимитов и тихих перезаписей.** Если какого-то значения
  в «Информации о станке» нет, соответствующий текущий лимит контроллера не
  меняется. Недопустимый целевой диапазон (`max ≤ 0` или `min ≥ max`) отменяет
  смену инструмента полностью — на контроллер ничего не отправляется, причина
  показывается пользователю. А переключение, которое заменило бы другие лимиты
  контроллера, требует подтверждающего клика с показом значений
  «старое → новое»; подтверждение запоминается для перехода (текущий
  диапазон → целевой), поэтому вручную изменённые позже лимиты никогда не
  перезаписываются молча.
- **Блокировки луча фокусировки.** Плагин никогда не вставляет `M5`/`S0`/`G0`
  в выполняющуюся программу: авто-ВЫКЛ через 5 минут (и любой другой «Выкл»)
  отправляется только когда станок в Idle, иначе ждёт Idle. Запуск программы
  при включённом луче сначала выключает луч. Перемещения (джог) в GRBL
  наследуют лазерное состояние, поэтому джог с включённым лучом прожёг бы линию
  по пути: по умолчанию начало джога отменяет его (realtime-отмена джога) и
  выключает луч в Idle (опция «Выключать луч фокусировки при начале
  перемещения» в настройках). Кнопка **«Выкл»** работает и во время джога.
- **Синхронизация с реальным состоянием станка.** `$$`, который Candle сам
  отправляет после подключения/сброса/хоуминга, распознаётся: режим и
  реальный `$30` контроллера (в подсказке кнопки) подтягиваются из ответа.
  Последний режим запоминается и восстанавливается при запуске. При
  отключении состояние сбрасывается — на следующем подключении всё
  считывается заново.
- **Единообразная локализация.** Один файл перевода (`translation_ru.qm`)
  покрывает всё — кнопки панели, подсказки, страницу настроек и все
  динамические сообщения — штатным механизмом Candle (см. ниже).

## Кнопки панели

| Кнопка | Что делает | Команды на станок |
|--------|------------|-------------------|
| **Режим** (иконка шпинделя/лазера) | смена инструмента | `M5`, `S0`, `G0`, `$32=x`; после `ok` — `$30=…`/`$31=…` по одному (если перезаписываются другие лимиты контроллера — подтверждающий клик) |
| **Фокус** | луч фокусировки ВКЛ/ВЫКЛ — только в лазерном режиме, авто-ВЫКЛ через 5 минут | запрос `$G`, затем `G1 F…` (без движения осей) + `M3 S…` / `M5` + `S0` + `G0 F…` |
| **Импульс** | тестовый импульс лазера — только в лазерном режиме | запрос `$G`, затем `G1 F…` + `M3 S…` + `G4 P…` + `M5` + `S0` + возврат `G0 F…` |
| **Выкл** | выключить лазер, отменить ожидающие лазерные действия — работает в Idle и во время джога | `M5` + `S0` + `G0` (во время джога: сначала realtime-отмена джога, «Выкл» — в Idle) |

Кнопки «Фокус», «Импульс» и «Выкл» автоматически скрываются в режиме
шпинделя. «Режим», «Фокус» и «Импульс» доступны только когда станок в Idle;
«Выкл» — в Idle и во время джога. Подсказка кнопки режима показывает реальный
`$30` контроллера и диапазон скоростей активного инструмента.

## Настройки плагина

- **Мощность фокусировки (S)** — мощность луча для кнопки «Фокус» (по умолчанию 10);
- **Импульс S / время (мс)** — параметры тестового импульса (по умолчанию
  S 10, 200 мс; учитывайте диапазон вашего лазера: на заводском диапазоне
  0..100 значение S 100 — это полная мощность);
- **Выключать луч фокусировки при начале перемещения** — включено по
  умолчанию. Снимайте галочку, только если сознательно двигаете станок
  (например, фокусируетесь по Z) при включённом луче;
- пояснение, как работает смена инструмента.

Скорости в настройках плагина не дублируются — они всегда берутся из
«Информации о станке».

## Локализация

Плагин использует **штатный механизм локализации Candle** — точно так же,
как официальный плагин usercommands. Один файл `translation_ru.qm` покрывает
все видимые строки:

- статические строки панели и настроек (подписи, подсказки, заполнители)
  переводит сам QUiLoader (контекст = `<class>` файла `.ui`);
- динамические сообщения используют `qsTr()` из скриптового движка
  (пустой контекст) — как в официальном плагине;
- заголовок панели «Шпиндель / Лазер» переводит сам Candle (контекст frmMain).

Плагин не определяет язык сам: Candle устанавливает подходящий
`translation_<язык>.qm` до загрузки скрипта, а при его отсутствии интерфейс
просто полностью английский — то есть он либо полностью английский, либо
полностью русский, без смеси. Чтобы добавить другой язык: скопируйте
`translation_ru.ts`, переведите строки и скомпилируйте командой
`lrelease translation_xx.ts`, полученный `.qm` положите рядом с файлами
плагина.

## Установка

1. Найдите папку с программой Candle (рядом с `candle.exe` / `candle`).
2. Скопируйте папку `spindle_laser` целиком в `candleplugins`
   (создайте её при необходимости):

```
Candle/
├── candle(.exe)
└── candleplugins/
    └── spindle_laser/
        ├── config.ini
        ├── script.js
        ├── widget.ui
        ├── settings.ui
        ├── translation_ru.ts
        ├── translation_ru.qm
        ├── LICENSE
        └── images/            иконки кнопок
```

3. Перезапустите Candle — в правой панельной области появится строка
   «Spindle / Laser».

## Требования

- актуальная сборка Candle с поддержкой JS-плагинов (папка `candleplugins`,
  лазерные поля в «Информации о станке», API хранилища плагинов; разработка —
  по текущим исходникам Denvi/Candle);
- **grbl v1.1+** — параметр `$32` «laser mode» появился только в v1.1;
- заполненная вкладка «Информация о станке»: скорость шпинделя мин/макс и
  мощность лазера мин/макс — именно из неё плагин берёт `$30`/`$31`.

## История версий

- **v11 (текущая)** — исправления по третьему аудиту: авто-выключение фокуса
  больше не вставляет `M5`/`S0`/`G0` в выполняющуюся программу — оно ждёт
  Idle; запуск программы при включённом луче сначала отправляет «Выкл»;
  джог, начатый при включённом луче, отменяется, а луч выключается (новая
  настройка, включена по умолчанию); кнопка «Выкл» работает во время джога,
  а панель больше не блокируется целиком вне Idle; импульс по умолчанию S 10
  вместо 100 (сохранённое 100 один раз мигрируется); клик до первого ответа
  `$$` больше не инвертирует реальный режим контроллера (запоминается
  режим, к которому стремился пользователь, и если контроллер уже в нём,
  ничего не меняется); подтверждение перезаписи привязано ко всему переходу,
  поэтому вручную изменённые `$30`/`$31` не перезаписываются молча
  (после обновления подтверждения запрашиваются заново один раз);
  неизменённые значения показываются как «(без изменений)» вместо «0 -> 0»;
  удалена неиспользуемая строка перевода.
- **v10** — исправления по второму аудиту: `$30`/`$31` пишутся
  последовательно (каждая запись с подтверждением) и в порядке, при котором
  промежуточный диапазон в EEPROM всегда допустим; перезапись отличающихся
  лимитов контроллера в первый раз требует подтверждающего клика (заводские
  значения «Информации о станке» больше не могут молча заменить реальные
  лимиты станка); лазерные действия перепроверяют режим и готовность в момент
  выстрела и отменяются сменой инструмента и всегда доступной кнопкой
  «Выкл»; ответы сверяются с точными строками отправленных команд (индекс
  -100 общий для всех плагинов); позднее подтверждение `$32` всё равно
  доводит лимиты до конца; пользовательские значения Focus/Pulse больше не
  переписываются под диапазон контроллера (ограничение — только в момент
  выстрела); слайдер скорости больше не схлопывается после OK в настройках
  Candle в лазерном режиме; модальное окно убрано; авто-выключение фокуса
  через 5 минут; Alarm/Sleep сбрасывают состояние фокуса; ряд исправлений
  блокировок, тайм-аутов и документации.
- **v9** — исправления по аудиту: смена инструмента отменяется
  (ничего не отправляется), если диапазон из «Информации о станке»
  недопустим (`max ≤ 0` или `min ≥ max` — в GRBL такой диапазон даёт
  полную мощность при любом S>0); отложенный запрос переключения после
  `$$` истекает через 5 с и отменяется внешним изменением `$32`; кнопка
  «Фокус» загорается только после подтверждения `M3` от GRBL, у ожидающих
  лазерных действий есть тайм-аут 5 с; ответы для конечных автоматов
  принимаются только на собственные команды плагина; выдуманные лимиты
  слайдера убраны; `translation_ru.qm` пересобран из `translation_ru.ts`
  (хардкод текста в настройках удалён); корневой README синхронизирован,
  добавлен файл LICENSE, удалён неиспользуемый `refresh.png`.
- **v8** — при успешном переключении явно отправляются обе команды
  `$30` и `$31`, если значения доступны в Machine info, даже если одна настройка
  уже совпадает с текущей. Благодаря этому `$31` не пропускается в журнале.
- **v7** — исправлены Focus/Pulse после сброса GRBL и ограничение тестовой
  мощности диапазоном `$31`–`$30`.
- **v6** — единая локализация штатным механизмом Candle: один
  `translation_ru.qm` покрывает панель, подсказки, настройки и динамические
  сообщения (строки `.ui` переводит QUiLoader, динамические — через
  `qsTr()`); собственного определения языка больше нет — интерфейс либо
  полностью английский, либо полностью русский.
- **v5** — смена скоростей при смене инструмента: при каждом переключении
  `$30`/`$31` подставляются из «Информации о станке» и пишутся сразу — одной
  посылкой `M5 + $32 + $30 + $31`, без цикла чтения/сравнения (grbl v1.1
  не пишет в EEPROM одинаковые значения).
- **v4** — смена скоростей через «считать → сравнить → записать отличающееся».
- **v3** — только интерфейсная смена скоростей (слайдер Candle), записей
  `$30`/`$31` не было совсем; блок лимитов убран со страницы настроек.
- **v2** — запись `$30`/`$31` сделана опциональной (по умолчанию выключена),
  значения по умолчанию — из «Информации о станке».
- **v1 (баг)** — при каждом переключении плагин записывал в EEPROM
  фиксированные `$30`/`$31` (10000/0 и 1000/0), портя реальные лимиты станка.
  Если grbl уже «испорчен» прошлой версией — восстановите `$30`/`$31`
  вручную из консоли Candle.



### Фокусировка и импульс в лазерном режиме GRBL

Команды Focus и Pulse сначала запрашивают `$G`, чтобы узнать текущую подачу
`F`, затем отправляют `G1 F...` без координат осей и `M3 S...`. В GRBL 1.1
подача `F` обязательна для `G1`, даже когда оси не перемещаются; это меняет
модальный режим для фокусировки без фактического движения. После теста плагин
отправляет `M5`, `S0`, возвращает `G0` и восстанавливает прежний `F`. Кнопки Focus/Pulse
недоступны, пока плагин не прочитает реальный максимум `$30`; фактически
отправляемая мощность ограничивается диапазоном `$31`/`$30` в момент
выстрела (и по-прежнему зависит от spindle override в Candle/GRBL, если он
задан). Луч фокусировки сам выключается через 5 минут. Используйте
минимальную практическую мощность и соответствующую защиту глаз.

Блокировки (v11): «Выкл» отправляется только когда станок в Idle и отправка
программы остановлена; в любом другом состоянии он запоминается и уходит,
как только станок вернулся в Idle (Alarm, Sleep и отключение его сбрасывают,
потому что GRBL уже остановил выход). Отправитель Candle сообщает
«передача» до отправки первой строки программы, поэтому «Выкл», отправленный
в этот момент, доходит до GRBL раньше задания. Во время джога GRBL принимает
только realtime-команды, поэтому плагин шлёт отмену джога (`0x85`), а «Выкл»
завершает в Idle. Джог определяется по отчёту о состоянии контроллера: очень
короткий джог, закончившийся до следующего отчёта, перехватить нельзя —
поэтому держите луч выключенным, когда двигаете станок не для фокусировки.

Переключение инструмента ждёт `ok` на `$32`, и только затем записывает
диапазон `$30`/`$31` из Machine info Candle. Модальные окна не используются (в некоторых окружениях QtScript класс
`QMessageBox` недоступен, а его вызов из обработчика ответов небезопасен);
подтверждение перезаписи лимитов сделано повторным кликом по кнопке режима. При отклонении `$32`
плагин перечитывает настройки, а не оставляет интерфейс в неподтверждённом
режиме. При переключении `$30`/`$31` намеренно могут изменяться под новый диапазон.

## Файлы

- `script.js` — логика плагина;
- `widget.ui` — панель (4 кнопки: Режим, Фокус, Импульс, Выкл);
- `settings.ui` — страница настроек (фокус, импульс, опция джога, пояснение);
- `translation_ru.ts` / `translation_ru.qm` — русская локализация (все
  строки);
- `config.ini` — манифест плагина.
